# Data and example resources

This directory contains ELVEX's versioned grammar examples and regression fixtures.

- [Examples](examples/README.md) — language-specific grammars, lexicons, input structures, and music projects.
- [Regression fixtures](regression/README.md) — input and expected-output files used by CTest.

Build and test the engine from the repository root as described in [INSTALL.md](../INSTALL.md). Example-specific commands are documented in their individual README files. Generated products and caches are not source files and are normally ignored by Git.
