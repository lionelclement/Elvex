# XML stylesheets

This directory contains XSLT utilities for ELVEX's optional XML and visual output workflows.

- [xml2CS-dot-graph.xsl](xml2CS-dot-graph.xsl) — transforms suitable XML representation data into Graphviz DOT graph text.

The core natural-language generator does not require XSLT for standard text output. See the [main README](../README.md) for the engine overview and [INSTALL.md](../INSTALL.md) for build requirements.
