# ELVEX language documentation

The authoritative source of the ELVEX language manual is [doc-en.tex](doc-en.tex), an English LaTeX document. A rendered version of the manual is available as [doc-en.pdf](doc-en.pdf).

The manual covers ELVEX's grammar formalism and feature-structure notation. For the current CMake installation and test workflow, use [INSTALL.md](../INSTALL.md) and [src/test/README.md](../src/test/README.md) instead of legacy build instructions.

LaTeX auxiliary files such as `.aux`, `.log` and `.synctex.gz` are build artifacts and do not need to be committed.
